ПУБЛИЧНЫЙ ОТЧЁТ ЦЕНТРА ГРАНИ ЗА 2025 ГОД
Версия для размещения в корне GitHub Pages

КАК ЗАГРУЗИТЬ

1. Распакуйте архив.
2. Загрузите всё его содержимое непосредственно в корень репозитория или в выбранную корневую папку публикации.
3. Файл index.html должен лежать рядом с папками assets и photos, а не внутри дополнительной внешней папки.
4. Обязательно загрузите файл .nojekyll.
5. После обновления сайта откройте страницу без кеша: Ctrl+F5.

- директор и восемь сотрудников представлены в редакционном фотоколлаже с постоянными подписями;

- добавлен отдельный раздел «Финансы и прозрачность» по аудированной отчётности;

- финансовый блок стал компактнее: поступления и выплаты сначала показаны как две краткие сводки, а подробности раскрываются по нажатию;

- исправлено пролистывание по пунктам верхнего меню: переход учитывает высоту закреплённой шапки и не перекрывает заголовки разделов;
