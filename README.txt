БИБЛИОТЕКА ОРГАНИЗАТОРА ДЕЛАЙ-САММИТА

Запуск
1. Распакуйте архив целиком.
2. Откройте index.html в современном браузере.

Пароль для входа
- Текущий пароль: start
- Чтобы заменить пароль, откройте app.js и найдите строку:
  const SITE_PASSWORD = "start";
- Замените только текст между кавычками и опубликуйте файлы заново.
- После успешного входа пароль повторно не запрашивается до закрытия вкладки/окна браузера.

Важно: это клиентская защита для ограничения обычного доступа. Пароль находится
в коде сайта, поэтому такой способ не подходит для хранения конфиденциальных данных.

Публикация на GitHub Pages
1. Загрузите содержимое этой папки в корень репозитория.
2. В Settings → Pages выберите Deploy from a branch и папку /(root).

Структура
- index.html — интерфейс;
- styles.css — фирменные стили;
- app.js — интерактивная логика;
- data/*.json — нормализованные данные;
- data/library-data.js — те же данные для запуска без локального сервера;
- materials/docs — DOCX-материалы форматов и приложения этапов (DOCX / XLSX);
- materials/pdf/formats — PDF чек-листов, сценариев и полных описаний;
- tools/xlsx — конструктор, план, реестр партнёров и бюджет;
- assets/images — фирменная иллюстрация.

Подборка, программа, статусы задач и бюджет сохраняются в localStorage браузера.

Реестр партнёров
- Изначально открывается одна пустая строка, без примеров и поиска.
- Можно добавлять строки, выбирать несколько типов вклада, менять статус
  и независимо отмечать шесть шагов. Все текстовые поля необязательны.
- Ответственный, контакты и комментарии вынесены в отдельные колонки.
- Удаление строки и очистку реестра можно отменить до следующего удаления
  или перезагрузки страницы. Очистка всего реестра требует подтверждения.
- Данные сохраняются в localStorage, ключ delai_partners_v1. Это сохранение
  для одного браузера и адреса сайта, а не личный кабинет. На общем компьютере
  данные доступны другим пользователям того же профиля браузера.
- Очистка данных браузера, смена браузера/устройства/адреса сайта не переносит
  реестр. В режиме инкогнито сохранение временное. Скачивайте резервные XLSX.
- «Скачать мой реестр · XLSX» выгружает только заполненные строки с текущими
  значениями. Галочки: Да/Нет. Типы вклада: список через точку с запятой.
  Статусы и Да/Нет можно выбирать из списков в Excel. Заголовок и первая
  колонка закреплены. XLSX можно редактировать и открыть в Google Таблицах.
- Обратный импорт XLSX в сайт не реализован.
- Google-таблица открывается отдельно как пример заполнения.
- На телефоне каждая строка раскрывается в форму кнопкой «Заполнить / изменить».
- Если браузер не разрешил сохранение, сайт показывает ошибку; скачивание
  введённых данных остаётся доступным. При конфликте двух вкладок данные
  не перезаписываются молча: можно скачать текущие или загрузить сохранённые.
- Логика раздела: partners.js; поля, списки и XLSX: partners-model.js;
  стили: partners.css. Другие разделы не используют эту модель.
- Для экспорта поставляется локальная ExcelJS 4.4.0 (лицензия MIT в vendor).
  Сохраняйте папку vendor целиком при загрузке сайта. Сеть для экспорта
  не требуется после загрузки файлов сайта; данные реестра не отправляются.

Материалы карточек
- Доступные PDF и DOCX показываются отдельными ссылками в одной строке.
- Полное описание хранится в materials/pdf/formats/<папка>/full_description.pdf.
- Ссылка «Материал Центра ГРАНИ» берётся из поля grani_url карточки.
- Если полного PDF пока нет, сохраняется существующая ссылка на Google-документ.
- Пустые разделы и обещания добавить материалы не выводятся.
- При ручном изменении путей обновляйте data/formats.json и formats внутри
  data/library-data.js одинаково: сайт использует последний файл и без сервера.

Чек-листы подготовки
- Вкладки: Руководство / План задач / Бюджет / Чек-листы / Партнёры.
- Четыре списка из исходных DOCX: выбор площадки (38 пунктов), подготовка
  помещения (22), материалы и оборудование (55), финальная проверка (52).
- Все списки сначала свёрнуты. Раскройте нужный, отметьте выполненное или
  выберите «Не требуется». Такие пункты исключаются из количества необходимых.
  Счётчик показывает выполнение списка, а не общую готовность мероприятия.
- «Показать невыполненные» скрывает выполненные и ненужные пункты.
- «Сбросить отметки» очищает только выбранный список после подтверждения.
- Отметки хранятся локально, отдельно для каждого списка:
  delai_checklist_v1_venue-selection, delai_checklist_v1_venue-preparation,
  delai_checklist_v1_equipment, delai_checklist_v1_final-check.
  Они сохраняются после обновления страницы, но не переносятся между
  устройствами/браузерами и удаляются при очистке данных браузера.
- На общем компьютере отметки доступны другим пользователям того же профиля.
- Повторная финальная проверка имеет собственные отметки, независимо от других
  списков. «Не требуется» не считается выполненным пунктом.
- Кнопки в этапах 06–07 открывают соответствующий интерактивный список.
  Прямая ссылка: #guide/checklists/<id>, например #guide/checklists/equipment.
- «Скачать шаблон · DOCX» скачивает исходный пустой документ с прежним
  оформлением. Отметки в скачиваемый шаблон не переносятся.
- Внешние материалы ГРАНИ представлены только ссылками; тексты не копируются.
- Данные: data/checklists.json и идентичные данные в data/checklists-data.js.
  Сайт читает второй файл, в том числе при открытии index.html без сервера.
- Логика и стили: checklists-model.js, checklists.js, checklists.css.
- В исходниках проекта scripts/build-checklists.py заново формирует данные
  из четырёх DOCX в materials/docs/stages. После изменения документов запустите
  из папки сайта: py scripts/build-checklists.py (требуется Python 3).
  Проверьте состав пунктов. Исходные DOCX скрипт не меняет.
- В онлайн-версии уточнены шесть пунктов об ограничениях площадки, чтобы было
  понятно, что означает отметка. Исходные формулировки сохранены в sourceText.

Источники и материалы руководства
- Ссылка «Источники» в футере открывает раздел #sources с семью ресурсами
  Центра ГРАНИ. Внешние материалы открываются в отдельной вкладке.
- В этапах 01 и 02 рабочие ссылки открывают вкладки «План задач» и «Партнёры».
- Новые приложения находятся в materials/docs/stages:
  partners_search — письмо партнёру, соглашение о сотрудничестве,
    благодарственное письмо и соглашение о совместной деятельности;
  participants_engagement — коммуникационный календарь (XLSX);
  summit_execution — памятка организатора и лист фиксации результатов;
  roadmap — шаблон дорожной карты (DOCX).
- Исходные файлы приложений сохранены без изменений.
- В этапах 02, 04, 09, 10, 11 и 12 приложения показаны в тексте однократно;
  дополнительный блок «Приложения этапа» для этих этапов отключён.
- В этапе 04 приглашение ведущему, памятка ведущего и контактный лист пока
  остаются текстовыми описаниями: исходные файлы не были приложены.
- В этапе 10 форма регистрации и анкета обратной связи, а в этапе 12 памятка
  по фиксации данных и сверкам с наставником остаются неактивными.
- Ссылки в руководстве описаны блоками type: "resources" в data/stages.json.
  kind: "internal" открывает вкладку (view), "download" скачивает файл (url,
  format), "external" открывает ресурс (url), "unavailable" выводит текст.
  show_materials: false скрывает отдельный блок приложений этапа.
- После изменения данных обновляйте stages в data/library-data.js теми же
  значениями. Раздел «Источники» редактируется в index.html (route-sources).

Скачивание своего плана и бюджета
- «Скачать мой план · XLSX» выгружает все 33 задачи с текущими статусами
  и ответственными. Поиск и фильтр не исключают задачи из файла.
  В Excel статусы можно менять через выпадающий список.
- «Скачать мой бюджет · XLSX» выгружает текущие статьи, количество, стоимость,
  вклад партнёров и лимит бюджета, включая добавленные строки и удаления.
  Последний ввод в поле также учитывается. Факт и комментарии из исходных
  данных сохранены в дополнительных колонках XLSX.
- Потребность, сумма из бюджета, итоги и остаток содержат формулы Excel.
  Партнёрский вклад сверх стоимости статьи не делает её сумму из бюджета
  отрицательной — расчёт совпадает с веб-версией.
- Файл фиксирует значения на момент нажатия кнопки. Его можно редактировать
  в Excel; обратного импорта на сайт нет. Google-таблицы остаются отдельными
  внешними ссылками, исходные XLSX в tools/xlsx не перезаписываются.
- Выгрузка работает локально через workbook-exports.js и библиотеку
  vendor/exceljs-4.4.0.min.js. При обновлении сайта сохраняйте оба файла.
